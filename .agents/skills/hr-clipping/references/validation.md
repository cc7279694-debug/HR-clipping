# 验证与适用边界

## 历史来源和本轮集成

原包关于视频信息、关键帧提取及静态检查的记录属于原包历史。原片和完整音轨没有在本轮重新检查；[来源归属](../../../../docs/SOURCE_PROVENANCE.md)与[原包收据](../../../../docs/source-package-checks.json)不替代本轮验证。

V1 仓库集成验证以[集成报告](../../../../docs/V1_INTEGRATION_REVIEW.md)为准；固定输入先定义在[行为场景](../../../../tests/skill-scenarios.md)，之后用独立代理处理相同输入并留脱敏答复。后续真实宿主的 V1-A1 结果在下文另列，不覆盖历史收据。

## 分项记录，不能互代

| 层级 | 能证明什么 | 不能证明什么 |
|---|---|---|
| 结构检查 | 必需文件、UTF-8、标识、相对文件目标、模板字段 | 任意 YAML 兼容、宿主发现、模型行为或视频效果 |
| 作者工具 quick_validate | 其实现覆盖的 frontmatter/命名/占位符检查 | 宿主自动加载、样片或跨软件兼容 |
| 独立代理行为样本 | 在列出的输入下实际读取规则并作答 | 宿主 `$hr-clipping` 自动注入、统计泛化、用户验收 |
| 宿主识别 | 菜单发现、真实调用的加载状态（须单独实测） | 能解码、转写、剪辑、渲染或重开工程 |
| 实际成片 | 对这份产物执行过的检查 | 其他素材、版本或软件能力自动通过 |

V1 固定基线时，宿主发现与正式调用为 NOT_RUN。后续 V1-A1 在本机 Codex 0.153.4 原生 app-server 新会话验证了目录发现、正式 Skill 输入、原生注入和母规范读取，结果 PASS；这不是代理手工读文件的替代证明。详情见[V1-A1 集中报告](../../../../docs/V1_A1_REPORT.md)。

桌面 GUI 菜单操作、跨工作区安装仍为 **NOT_RUN**；只打开父工作区不会向下发现子仓库 Skill。样片剪辑、完整播放、完整试听及编辑器工程重开仍 **NOT_RUN**，V1-A1 原因是授权目录没有合适自有音视频。文字计划继承不等于实际视频效果。

纯文字 `$hr-clipping` 提交的补测为 **BLOCKED**：初始化阶段遇本机状态库和本地控制 socket 问题，未进入模型回合。已完成的结构化原生调用有独立证据；不能据此升级纯文字或 GUI 路径，也不能把初始化问题归因为 Skill 解析失败。

## 后续实际制作时

素材可访问、视频可解码、音轨可读、转写、校对、叠加小窗、字幕、导出和工程重开逐项记录。没有执行的项目写 NOT_RUN；受环境阻塞写具体原因。工具声称成功、文件存在、实际可播放是不同证据。

可在用户另行指定素材和制作任务后，用 20–30 秒真实片段验证 P→D→R 与手机可读性。一次样片也不能宣称完整自动化能力已打通。
