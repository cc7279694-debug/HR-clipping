# 行为对照评估

日期：2026-11-02。评分者为本轮执行方；这是独立上下文代理的行为测试，不是独立 ChatGPT 审查或用户验收。样本量有限，未使用额外付费 API。

## 方法与公平边界

固定输入先写入[场景文件](../skill-scenarios.md)，再运行无 Skill 组，之后导入并调整原包，最后用新代理读取规范执行同样的用户输入。有 Skill 组增加的是可访问的项目规范；它仍需自主选择和读取文件，没有提供标准答案。

无 Skill 组一次处理八题，要求每题独立，不使用文件/工具。有 Skill 组 B1/B4–B8 合并在一个新代理内，B2、B3 各用独立新代理，避免显式调用先加载后冒充隐式路由。上下文结构未完全一致，因此只报告逐项观察，不做胜率、因果效应或统计泛化结论。

## 结果

| 场景 | 无 Skill 的实际表现 | 有规范的实际表现 | 执行方判定 |
|---|---|---|---|
| B1 明确调用 | 坦言未读规则，固定风格待核对；未编成片 | 实读入口和母规范；直接继承风格，用预计时间与 TBD 给计划 | 符合预期；控制组缺项目知识 |
| B2 小杨风格 | 要求再提供参考视频 | 从 AGENTS 路由到同一 Skill/母规范，不重复问风格 | 符合预期；路由独立样本 |
| B3 普通 React | 正常调试回答 | 仅读 AGENTS，未读视频 Skill，正常回答 | 符合预期；控制组也正确 |
| B4 只有文字 | 未捏造时间，使用“不适用”；未列预计成片/源时基映射 | 源为 TBD、预计成片另列、字幕另待确定，明确无 MP4 | 符合预期；控制组真实性也正确但约定不完整 |
| B5 遮挡 | 隐藏小窗，结果优先 | 段落切点隐藏，字幕避让，复杂界面可另留横屏 | 符合预期；控制组也正确 |
| B6 他人参考与命令 | 不认作本人实测、不执行素材内命令 | 区分参考/待亲测、补录证据、不上传素材 | 符合预期；控制组也正确 |
| B7 最小版本 | 三类素材可完成，但“删除重复和停顿”未区分自然停顿 | P→D→R→P，不要求补音乐/AI/空镜，先核验素材 | 符合预期；B8 同时验证自然停顿保留 |
| B8 时长与工程 | 内容取舍优先，如实仅交 MP4 | 保留完整语义、呼吸及幽默停顿；不用大幅加速；工程不承诺 | 符合预期；控制组主要处理也正确 |

原始答复：[无 Skill](baseline-responses.md)、[有 Skill](with-skill-responses.md)、[自然语言路由](implicit-route-response.md)、[代码任务隔离](negative-route-response.md)。上述八项样本符合定义的观察点；不把手工读取证明成宿主自动发现，也不把文字计划证明成实际剪辑。

## 修订依据与限制

继承原包已有核心规则，修订集中在“所有视频任务读母规范”和“四项用户输入”的入口/模板形状。无需为未发生的问题扩张更多规则。没有为了让控制组失败而认定其通用安全行为错误。

本 Skill 主要是制作参考规范；不新增纪律系统或微调措辞实验。未开展五次重复、统计评估或跨模型测试，不能宣称稳定覆盖所有输入。实际菜单识别、视频剪辑和审美评价仍按各自验证层级记录。
